# Projeto-orelha-base-
trabalho para o capas (replit + expo go)

## 📱 processo de "Instalação"
- 1. ter o app do "Expo GO" no aparelho
- 2. nodejs instalado (node.js | versão moderna => 26.x (Current) | estabilidade para produção => 24.x+ (LTS))
- 3. Execução
-- entrar no repositório 
```sh
cd orelha
```
-- rodar (servidor local)
```sh
npx expo start

```
- 4. pegar __QR Code__ ou __Link__ para o expo go e depois abrir
